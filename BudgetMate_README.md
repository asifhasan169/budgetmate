# BudgetMate

> **Shared expenses, simplified.**

BudgetMate is a modern roommate expense management web application that makes it easy to track shared expenses, split bills fairly, manage monthly budgets, and settle balances through a clean, minimalist interface.

## ✨ Features

- 🔐 Secure authentication with Supabase Auth
- 👥 Shared rooms with roommate invitations
- 💸 Add and split shared expenses
- 📊 Expense analytics and spending insights
- 💰 Settlement calculator
- 📅 Monthly budget tracking
- 🖼️ Profile management with avatar upload
- 🔒 Row Level Security (RLS)
- 📱 Installable Progressive Web App (PWA)

## 🛠️ Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Supabase (Auth, PostgreSQL, Storage, RLS)
- Recharts
- Lucide Icons

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm
- A Supabase project

### Installation

```bash
git clone <your-repository-url>
cd budgetmate
npm install
```

### Environment Variables

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### Run

```bash
npm run dev
```

Open: http://localhost:5173
